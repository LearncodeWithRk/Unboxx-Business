# **App Name**: CleanCanvas

## Core Features:

- Tailwind CSS Setup: Configure Tailwind CSS with a custom 'Refold' theme (Background: #050505, Border: white/10, Primary: emerald-500).
- Directory Structure: Create folders for @/components/ui (atomic elements), @/components/sections (large layout blocks), and @/lib (utilities).
- Typography Configuration: Configure 'Inter' as the primary font in layout.tsx using next/font/google.
- Global Styles: Remove default Next.js boilerplate, add smooth scroll behavior and default text color of slate-200 in globals.css.
- Root Layout Setup: Create a clean layout.tsx with a simple <main> wrapper and a page.tsx that exports an empty div with a 'Hello World' heading.

## Style Guidelines:

- Primary color: Emerald green (#34D399) for a vibrant and modern look, reflecting the specified emerald-500 from the 'Refold' theme.
- Background color: Dark gray (#050505) to align with the 'Refold' theme's background color. Heavily desaturated to around 20% to maintain the dark tone.
- Accent color: Teal (#2DD4BF), an analogous color to emerald, offering a contrasting vibrant pop to call attention to details and CTAs.
- Body and headline font: 'Inter' (sans-serif) as requested; suitable for both headlines and body text.
- Implement a clean, minimalist layout to provide a solid foundation, enabling content to take center stage with sufficient spacing.
- Incorporate subtle transitions for interactive elements. This delivers a visually delightful experience without drawing attention.
